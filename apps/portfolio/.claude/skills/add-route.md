Follow these steps in order when adding a new page to the portfolio.

## Step 1 — Create the route file

Create `src/routes/<slug>.tsx`. Use the English canonical slug as the filename
(the translated-pathnames mapping handles locale-specific URLs).

Minimal template:
```tsx
import { createFileRoute } from "@tanstack/react-router";
import { seo } from "~/utils/seo";

export const Route = createFileRoute("/<slug>")({
  head: () => ({
    meta: [
      ...seo({
        title: "Nicolas Thouvenin - <Page Title>",
        description: "<Page description for SEO>",
        image: "https://nicolas-thouvenin.dev/logos/vertical.png",
        url: "https://nicolas-thouvenin.dev/<slug>",
        site_name: "Nicolas Thouvenin - Portfolio",
      }),
    ],
  }),
  component: PageComponent,
});

function PageComponent() {
  return <></>;
}
```

If the page needs locale-aware content, import `m` from `~/lib/paraglide/messages`
and add the required keys following the `i18n-message` skill.

## Step 2 — Add the translated pathname mapping

Edit `src/utils/translated-pathnames.ts`. Add an entry to the object passed to
`createTranslatedPathnames`:

```ts
"/slug": {
  fr: "/french-slug",
  en: "/english-slug",
},
```

If the URL is the same in both locales, use the same string for both.
If the locale URLs differ (like `/cv` ↔ `/resume`), specify each explicitly.

## Step 3 — Add to prerender config

Edit `src/utils/prerender.ts`. Add the route path to the array:

```ts
export const prerenderRoutes = ["/", "/cv", "/<new-slug>"].map((path) => ({
  path: localizeHref(path),
  prerender: { enabled: true },
}));
```

`localizeHref` expands the path to all locale variants automatically.

## Step 4 — Register in routeTree (auto-generated)

The route tree (`src/routeTree.gen.ts`) is auto-generated by TanStack Router
during `pnpm dev` or `pnpm build`. Do not edit it manually.
Start the dev server once to trigger regeneration.

## Checklist

- [ ] `src/routes/<slug>.tsx` created with `createFileRoute`, `head()`, component
- [ ] `seo()` called with all five fields
- [ ] Entry added to `translatedPathnames` in `src/utils/translated-pathnames.ts`
- [ ] Path added to `prerenderRoutes` in `src/utils/prerender.ts`
- [ ] If new i18n strings needed: followed `i18n-message` skill first
- [ ] Dev server started to regenerate `src/routeTree.gen.ts`
